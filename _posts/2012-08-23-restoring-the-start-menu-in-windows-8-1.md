Metro is the term for the new *User Interface* of windows 8. With its display of boxes that were indeed designed for this tou*chscreen* device, it may be very unsuitable for use on computers that still use a pointing device, in this case such as a mouse. Because the buttons are so large, when using a mouse, the distance to move from 1 button to another will be very far.

That was also part of my experience using windows 8, and in the end I removed it and went back to windows 7 :D

Well, for those of you who want to use Windows 8 but don't feel comfortable using Metro, there's free and open-source software that will replace your start menu appearance.
