My second Antivirus work, made using VB6. A combination of Sigma (VB) + GASAV (VB) + Sigma (Delphi). The merging of these programs makes SIG even stronger in both defense and malware detection.

The features of SIG are :

- Fast and light scanning! <>- Uses a double checksum that doesn't reduce scanning speed, and makes scanning more accurate (Cut500 and SIG Pattern) - Supports detection of foreign viruses (Virut variant, Sality variant,  Resur, Polyene, Slugin, Lamechi, etc.) - Smart-Terminator, to kill programs in a ‘sadistic’ way wakakak ![:D](http://s0.wp.com/wp-includes/images/smilies/icon_biggrin.gif?m=1129645325g) - File Monitoring, able to detect files that are **created, edited, deleted, moved, renamed, etc.** - AntiKill component integrated into the Main Scanner. - PE Heuristic (Bad Section, Bad Entrypoint, Dropper, etc.) - Real-Time Protection with SIG – File Radar supported by Real Time Communication technology with the main scanner. - Plugin support using ActiveX Library [more info ?](http://sigcontrol.wordpress.com/2011/02/15/buat-plugin-untuk-sig/) - Hell Gate Component as an internal Firewall - And many more
