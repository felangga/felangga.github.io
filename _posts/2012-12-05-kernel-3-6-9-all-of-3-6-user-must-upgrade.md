Kernel 3.6.9 has been released at [www.kernel.org](http://www.kernel.org/), or you can download it [here](http://www.kernel.org/pub/linux/kernel/v3.0/linux-3.6.9.tar.bz2). It wasn't long ago that 3.6.8 came out, and 3.6.9 is already out. I still haven't tried this new kernel, still haven't had time to download and compile it. According to *softpedia*, kernel 3.6.9 has many upgrades to drivers, updates to the file system (Ext4 and JFFS), sound fixes, networking fixes, and many other tweaks.

Maybe after finals, I’ll try using this version, because it seems quite promising regarding driver support :)
