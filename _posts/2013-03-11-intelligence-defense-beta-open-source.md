A game that we made (me + dani) for an artificial intelligence assignment. This game is quite simple, with the gameplay rule being that you must kill passing enemies using only Towers and Fortresses arranged according to the formation desired by the user. Enemies will walk from **Enter Zone** to **Exit Zone** and the user must create 5 towers and 5 fortresses to block and kill enemy players from reaching **Exit Zone**. The algorithm used is [Hill Climbing](http://en.wikipedia.org/wiki/Hill_climbing).

![Intelligence Defense -- Beta [Open Source]](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEiAaG9IEvbQmHQRApd323QQXQxLBWk0g2KWEoqLwpBWe6NkTgh5_ShN_5kIhJDv07sxEHvNAaaXpZqE1p4Y6gWsYiMmjY0BwwJT82M-yKdY1amBj31N__GLWr4hDqK2VbgpNTdgM2mPyVQ/s1600/ss.JPG)

Before playing, the computer will test the possible paths to run using that algorithm, and after finding the best one, the computer will take it and run along that path.

Without further ado, please download this program compiled using Microsoft Visual Basic 6.0 [source code + report results.](http://fcomp.3owl.com/download/AI.rar)
