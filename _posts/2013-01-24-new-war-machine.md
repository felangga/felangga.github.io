Christmas holiday 2012 brought quite a blessing for me, because many of my relatives gave me lots of souvenirs and money :) hikhik #matahijau

Because the money I’d saved up was pretty decent, I planned to build a PC for the first time, hoping it would successfully power on :D After doing the math and having to sell my beloved phone, a PC finally came together yesterday, January 23, 2013, with the following specs

- Processor AMD A8 - 5600K

- Motherboard ASROCK FM2A75M-DGS

- RAM 4GB - GSKILL

- Harddisk WDC 320GB

For the PSU and the case, I'm still using my old computer. The PSU uses an EPRO 450 watt. That's enough for this AMD APU, as long as you don't use an A10. This AMD A8 uses a HD 7650 VGA with shared memory from the RAM. So my RAM has to be split between the processor and the VGA. This can be configured in the UEFI menu under the Northbridge section.
