The complicated problem we face when deleting a linux partition. Deleting it is indeed easy, but if it's not deleted correctly, the computer will definitely have booting problems. Yes, that's because GRUB wasn't deleted properly.

If it has already happened, and you really need Windows on your computer. The condition is that you must have a master copy of Windows, and perform a repair with it.

Use the Windows master and go into system command or command prompt. Simple, just type FIXMBR and press enter. Try restarting to see if it can boot again. . :)
