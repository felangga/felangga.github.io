If you want to search for files on Rapidshare on Google, here are the ways.. Type the following code on the Google homepage.

> site: rapidshare.de -filetype: zip OR rar daterange :2453402-2453412

This is the rapidshare.de search site for every rar or zip file that has been indexed between February 1-11.

> dvd site: rapidshare.de-filetype: zip OR rar daterange :2453402-2453412

This is the same search but specifically for the "dvd" search with the same search criteria, so anything posted with the word dvd in it will be found. There are three criteria in particular to keep in mind when doing this search.site: the chosen site to search

- filetype: Filetypes you want to search, if you put "OR" then the file type can be more than 1.

- daterange: (start - enddate)

This daterange uses the "julian calendar", a converter can be found here: [http://aa.usno.navy.mil/data/docs/JulianDate.html](http://aa.usno.navy.mil/data/docs/JulianDate.html)
