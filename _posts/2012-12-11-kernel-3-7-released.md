Today I read a tweet from a lecturer saying that kernel 3.7 has been officially released by Linux and can be enjoyed at [www.kernel.org](http://www.kernel.org/). Not only kernel 3.7, kernel 3.6.10 has also been released on the site. According to his explanation, this new kernel already supports ARM64, Intel and Radeon card updates, as well as fixes for the ext4 file system that recently had problems in kernel 3.6.

According to information from [softpedia](http://news.softpedia.com/news/Linux-Kernel-3-7-Has-Been-Officially-Released-313602.shtml), some of the updates made in this kernel version are as follows :

· Support for 64-bit ARM;
· Better power management for Radeon GPUs;
· Better support for Intel graphics;
· Improved Nouveau DRM video driver;
· EXT4 improvements;
· Btrfs hole-punching;
· Improved support for Intel AES-NI;
· Support for Xen EFI video mode;
· IPv6 Netfilter enhancements;
· ARM Xen virtualization support for Cortex-A15;
· Nintendo Wii Balance Board driver support;
· Audio Run-Time Power Management;
· Support for JFS TRIM on SSDs;
· Support for Oracle SPARC-T4.

For more details, you can read it at [kernelnewbies.org](http://kernelnewbies.org/Linux_3.7_DriverArch). There it explains in detail all the updates made in kernel 3.7. Right now I still haven't had time to try it; maybe tomorrow I'll try to download it and give it a taste :)
