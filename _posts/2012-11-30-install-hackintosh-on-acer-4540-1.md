A few days ago, seeing a friend who wanted to install Hackintosh on his computer made me want to have a Hackintosh on my computer too. Hackintosh is a hacked Macintosh that can run on PC platforms (Intel or AMD). Maybe it was previously explained by Ucup in this post [http://www.f-comp.com/2012/10/install-os-x-di-pc.html](http://www.f-comp.com/2012/10/install-os-x-di-pc.html).

So in the end I was taught by Ucup to install hackintosh on my computer. My computer is an ACER 4540 with specifications

- AMD Turion X2

- ATI HD 4200

- RAM 3GB

- HDD 320 GB

The laptop is actually quite outdated, and can only support Mac OS 10.6 or Snow Leopard. The result was quite encouraging, but there is 1 issue that hasn't been fully resolved yet, namely the VGA problem. The following are devices that work right away with the built-in Hackintosh drivers

- Sound

- WiFi (Atheros)

- Bluetooth

- Touchpad

- WebCam

It's no big deal, it was just for trying things out. The result was quite satisfying, but I'm still not fully satisfied because the VGA isn't fully right yet, it's still Low Res (1024x768). It's really unpleasant to look at; my computer's standard resolution is 1366x768. Still doing a lot of experimenting to change the resolution to Full Res.
