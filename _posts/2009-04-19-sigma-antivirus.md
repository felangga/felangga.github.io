Huh, finally this project is done, I made this antivirus for freeware circles and virus-hating circles... This antivirus isn't really super advanced like other Indonesian AVs, but I think it's enough to detect a virus, using CRC32, MD5, and HEX methods. MD5 detects quite well compared to CRC32 because the antivirus database fingerprint also includes the virus file size. For the HEX method, it reads the hexadecimal code inside a file and matches it against its database signature. I made this AV using Delphi 7.0; right now I haven't distributed the source code yet, but if there are lots of requests, I'll distribute it to the Internet soon, so, give comments often!!!
