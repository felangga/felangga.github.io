SIG plugins are made using ActiveX, so you can use any programming language that already supports ActiveX. There have already been 3 plugins since this article was written, both of them (Antikill and Process View) use VB, while the Zulanick Healer plugin was made using Delphi. Unfortunately I don't have much time to write this article, so the only thing I got around to covering is the tutorial for making plugins using VB; the Delphi one will be covered next if I get the chance.
- Download tutorial [here](http://xtfcomp.comxa.com/SIG/Plugins.doc).
- Download contoh plugin [here](http://xtfcomp.comxa.com/SIG/antikill.rar).
