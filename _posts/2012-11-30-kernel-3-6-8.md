Not long ago, kernel 3.6.8 has appeared again, which you can download at www.kernel.org. Some of the fixes include:

- ALSA: usb-audio: Fix crash at re-preparing the PCM stream

- ALSA: hda - Fix invalid connections in VT1802 codec

- ALSA: hda - Fix empty DAC filling in patch_via.c

- ALSA: HDA: Fix digital microphone on CS420x

- tcp: fix retransmission

For me, there doesn't seem to be anything that warrants updating to this version yet. I'm still on 3.6.6; yesterday I wanted to update to 3.6.7, but 3.6.8 showed up right away. I think it's better to wait for 3.7 to be officially released :)
